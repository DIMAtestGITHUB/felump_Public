# 🎵 Discord Music Bot

Простой Discord-бот, который умеет заходить в голосовой канал и проигрывать музыку с YouTube.

## 🚀 Возможности

- Подключается к голосовому каналу
- Воспроизводит музыку по ссылке
- Использует YouTube как источник
- Работает быстро и без лишних сложностей

## 🛠️ Что нужно

Перед запуском убедись, что у тебя есть:

- Python 3.10+
- ffmpeg (добавлен в PATH или указан в коде)
- Discord bot token
